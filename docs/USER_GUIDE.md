## 1. 개요 및 핵심 개념

### 1.1 WITH+란?

WITH+는 **"함께할수록 더해지는 가치"** 를 내세운 **커뮤니티 기반 프리미엄 쇼핑몰**입니다. 건강기능식품·생활용품 등을 판매하는 일반 커머스 기능 위에, **커뮤니티(분양 조직) 적립**이라는 독특한 개념을 결합했습니다. 회원이 상품을 구매할 때마다 **개인 마일리지**와 함께 소속·선택 **커뮤니티(공동체)에도 적립금**이 쌓입니다.

### 1.2 시스템 구조 (정적 프론트 + Express 백엔드)

이 플랫폼은 일반적인 React/Next.js 단일 앱이 아니라, 아래 두 부분으로 구성된 **정적 HTML + API 서버** 구조입니다.

| 구성 요소 | 내용 |
|---|---|
| **프론트엔드** | `public/` 폴더의 정적 HTML 파일들(`index.html`, `cart.html`, `admin.html` 등). 각 페이지는 브라우저에서 바닐라 JavaScript로 백엔드 API를 호출해 데이터를 받아 화면을 그립니다. |
| **공통 스크립트** | `public/withplus-common.js` — 모든 페이지가 공유하는 공통 로직(`WithPlus` 객체: 로그인 상태, API 호출, HTML 이스케이프 등). |
| **백엔드** | 루트의 `server.js`(약 871KB, Node.js + Express 5). 상품·주문·회원·정산 등 **322개의 API 라우트**와 정적 파일 서빙, 페이지 라우팅을 모두 담당합니다. |
| **데이터베이스** | Supabase(PostgreSQL). `@supabase/supabase-js`로 연결합니다. |
| **배포** | Render(`render.yaml` 블루프린트). 싱가포르 리전 web 서비스, `npm start`(=`node server.js`)로 실행. 헬스체크 경로는 `/api/health`. main 브랜치 푸시 시 자동 배포. (이전엔 EC2 → 2026-08-17 Render로 이전) |

### 1.3 핵심 개념 용어

- **마일리지(개인 적립)**: 구매 시 회원 개인에게 쌓이는 포인트. 다음 구매 시 사용.
- **커뮤니티 적립(공동체 적립금)**: 구매 금액 일부가 소속/선택 **커뮤니티**(교회·성당·사찰·단체 등 "분양 조직")에 쌓이는 금액. 커뮤니티는 이를 정산받을 수 있습니다.
- **분양 조직(커뮤니티)**: WITH+가 "분양"하는 커뮤니티 단위. 각 조직은 전용 랜딩페이지, 전용 상품/카테고리 노출, 전용 조직 관리자 화면을 가질 수 있습니다.
- **회원 등급(멤버 등급)**: 구매 실적 등에 따른 등급. 등급별 적립율 등이 달라질 수 있습니다.
- **헌금·후원(Offering)**: 종교·단체 조직을 대상으로 한 헌금/후원 결제 기능(십일조·교무금·시주 등 항목).
- **정산(Settlement)**: 공급사/분양 조직에 매출 대비 수수료·적립금을 현금 지급하는 절차(원천징수 3.3%·세금계산서 처리 포함).
- **대표자(Owner)**: 원가·마진·정산 등 민감 정보 열람 권한을 가진 최상위 계정. 2단계 인증(2FA) 필수.

## 2. 시작하기 — 접속·회원가입·로그인

### 2.1 접속

웹 브라우저에서 WITH+ 사이트 주소로 접속합니다. 첫 화면은 메인(`index.html` / 경로 `/`)입니다. PWA(Progressive Web App)를 지원하여(`manifest.json`, `sw.js`) 모바일에서 홈 화면에 추가해 앱처럼 사용할 수 있으며, 오프라인 시 `offline.html` 안내 화면이 표시됩니다.

### 2.2 회원가입 (join.html, `/join`)

1. 상단/로그인 화면에서 "회원가입"으로 이동합니다.
2. 아래 항목을 입력합니다.
   - **이메일** (로그인 ID로 사용)
   - **비밀번호** / **비밀번호 확인**
   - **추천인 코드** (선택) — 지인에게 받은 추천 코드가 있으면 입력 (추천인 프로그램 혜택 적용)
   - **마케팅 정보 활용 동의** (선택) — 맞춤 혜택·이벤트 안내용. 가입 후 마이페이지에서 언제든 변경 가능.
3. 가입 완료 후 시작 안내(`welcome.html`, `/welcome`) 화면으로 이동할 수 있습니다.

> 주의: 마케팅 동의 여부는 이후 **타겟 마케팅 발송 대상**을 결정합니다. 동의하지 않은 회원은 관리자가 어떤 조건을 걸어도 알림 대상에 포함되지 않습니다.

### 2.3 휴대폰 본인인증 (verify-phone.html, `/verify-phone`)

일부 기능(결제·주문 등)에는 휴대폰 본인인증이 필요할 수 있습니다. 안내에 따라 휴대폰 번호 인증을 진행합니다.

### 2.4 로그인 (login.html, `/login`)

1. 이메일/비밀번호로 로그인합니다.
2. **소셜 로그인**도 지원합니다("또는 소셜 계정으로 로그인"). 네이버 로그인이 백엔드에 연동되어 있습니다(`/api/auth/naver/login`, `/api/auth/naver/callback`).
3. 로그인 후 토큰은 공통 스크립트(`withplus-common.js`)가 관리하며, 이후 모든 API 호출에 사용됩니다.

### 2.5 비밀번호 재설정 (reset-password.html, `/reset-password`)

비밀번호를 잊은 경우 재설정 화면에서 이메일로 재설정 절차를 진행합니다.

## 3. 사용자 역할 구분

| 역할 | 접근 화면 | 설명 |
|---|---|---|
| **비회원(게스트)** | 메인·카테고리·상품·검색·커뮤니티·정보 페이지 | 둘러보기 가능. 구매·장바구니 저장·커뮤니티 가입 등은 로그인 필요. |
| **일반 회원(user)** | 위 + 마이페이지·장바구니·주문·리뷰·찜·정기배송·헌금/후원 | 쇼핑 전 기능 사용. |
| **사업자 회원** | + 도매몰(wholesale.html) | 사업자 회원 승인 후 도매 전용가로 주문. |
| **공급자(provider)** | 관리자 화면 중 공급자 전용(주문·매출 리포트 등) | 공급사 계정. `/api/provider/*` 사용. |
| **조직 관리자(community admin)** | 조직 전용 관리 화면 | 자신이 담당하는 커뮤니티의 회원·주문·적립·헌금·정산만 열람/관리. 다른 조직 데이터 접근 불가. |
| **관리자(admin / super_admin)** | admin.html 전체 | 상품·회원·주문·마케팅·정산 등 전체 운영. |
| **대표자(owner)** | + 원가/마진/정산 열람, 대표자 보안설정 | 민감 정보 열람 권한. 2단계 인증 필수. |

> 접근 통제: 관리자 페이지는 "공급자(provider) 또는 관리자(admin) 권한이 있는 계정"만 열 수 있습니다. 권한이 없으면 "관리자 페이지 접근 권한이 없습니다" 안내가 표시됩니다.

## 4. 화면별 상세 사용법

각 화면은 **목적 → 주요 기능 → 사용 단계 → 주의**로 설명합니다.

### 4.1 일반 사용자 화면

#### 메인 (index.html, `/`)

- **목적**: 플랫폼 진입점 및 큐레이션.
- **주요 기능**: 카테고리 둘러보기, 신규 회원 혜택, VIP 회원 전용 섹션, 커뮤니티 참여 안내, 베스트 상품, 최근 본 상품, 실시간 활동, 최근 리뷰, 플랫폼 현황, **마일리지 현황**, WITH+ 커뮤니티 소개. 로그인 상태에 따라 개인화 섹션(`/api/me/home-sections`)이 표시됩니다.
- **사용 단계**: 원하는 섹션/상품 클릭 → 카테고리 또는 상품 상세로 이동.
- **주의**: 비로그인 시 마일리지·개인화 섹션은 제한됩니다.

#### 카테고리 (category.html, `/category/:slug`)

- **목적**: 카테고리별 상품 목록.
- **주요 기능**: 선택 카테고리의 상품을 불러와 그리드로 표시. 상품이 없으면 "준비 중"/"등록된 상품이 없습니다" 안내.
- **사용 단계**: 카테고리 선택 → 상품 카드 클릭 → 상세로 이동.

#### 상품 상세 (product.html, `/product/:id`)

- **목적**: 개별 상품 구매·정보 확인.
- **주요 기능**: 상세 정보, **함께 구매한 상품**, **비슷한 상품**, **이 공급사의 다른 상품**, **상품 리뷰**, 가격 이력, 옵션(variant) 선택, 장바구니 담기, 재입고 알림 신청.
- **사용 단계**: 옵션 선택 → 수량 지정 → 장바구니 담기 또는 바로 주문. 품절 시 "재입고 알림" 신청.
- **주의**: 옵션이 있는 상품은 옵션별 재고로 관리됩니다.

#### 검색 (search.html, `/search`)

- **목적**: 키워드 상품 검색.
- **주요 기능**: 자동완성(`/api/search/autocomplete`), 인기 검색어(`/api/search/popular`), 검색 결과 목록.
- **사용 단계**: 검색어 입력 → 결과 확인. 결과 없으면 안내 표시.

#### 장바구니 & 주문 (cart.html, `/cart`)

- **목적**: 담은 상품 확인 및 주문/결제.
- **주요 기능**: 수량 변경·삭제, 함께 구매하면 좋은 상품 추천, 쿠폰 적용(`/api/coupons/validate`, `best-available`), 마일리지 사용, 배송지 선택, **결제**. 결제 수단: **신용카드(토스)**, **카카오페이**, **네이버페이**.
- **사용 단계**:
  1. 장바구니 상품/수량 확인
  2. 쿠폰·마일리지 적용
  3. 배송지 선택(또는 추가)
  4. 결제 수단 선택 후 결제 진행
  5. 완료 시 "주문이 완료되었습니다!" / 결제 결과(payment-result.html) 확인
- **주의**: 비로그인·빈 장바구니 시 주문 불가. 결제 승인은 각 PG사 콜백으로 확정됩니다(토스 confirm, 카카오/네이버 approve).

#### 마이페이지 (mypage.html, `/mypage`)

- **목적**: 개인 활동·혜택 통합 관리.
- **주요 기능**:
  - **주문 내역** 조회 및 주문취소/반품·교환 신청
  - **배송지 관리**(추가/수정/삭제/기본 배송지 설정)
  - **찜한 상품**(위시리스트)
  - **정기배송** 관리(조회/수정/해지)
  - **마일리지**: 사용 가능 마일리지, 총 적립, 개인 적립 현황
  - **출석체크**(출석 이벤트 적립)
  - **시리얼 쿠폰 등록**(이벤트로 받은 코드 입력 → 마일리지 적립)
  - **추천인 프로그램**(내 추천 코드·실적)
  - **회원탈퇴**
- **사용 단계**: 좌측/탭에서 원하는 항목 선택 → 조회·변경.
- **주의**: 로그인 필수. 회원탈퇴는 되돌릴 수 없으므로 신중히 진행.

#### 내 정보 (my-info.html)

- **목적**: 개인정보(프로필) 확인·수정(`/api/me`, `/api/me/profile`).

#### 커뮤니티 목록 (communities.html, `/communities`)

- **목적**: 개설된 커뮤니티(분양 조직) 탐색·가입.
- **주요 기능**: 커뮤니티 목록·검색, 상세 보기, **가입**(`/api/communities/:slug/join`), 내 기여 적립금 확인.
- **사용 단계**: 커뮤니티 선택 → 소개 확인 → 가입 → 이후 구매 시 해당 커뮤니티에 적립.

#### 커뮤니티 랜딩 (community-landing.html, `/c/:slug`)

- **목적**: 개별 분양 커뮤니티 전용 소개·쇼핑 랜딩페이지.
- **주요 기능**: 조직 로고·소개·히어로, **공동체 총 적립금**, **내가 기여한 적립금**, 회원 혜택, 공동체 적립 혜택 안내. "구매 금액의 일부가 공동체에 적립됩니다". 랜딩 템플릿은 관리자가 선택(미니멀 리스트형 등).

#### 헌금·후원 (offering.html, `/give/:slug`)

- **목적**: 종교·단체 조직에 헌금/후원 결제.
- **주요 기능**: 조직 선택 → 헌금 항목(십일조/교무금/시주 등, 조직 유형별 기본 제공) 선택 → 금액 입력 → 결제(토스 confirm). **내 헌금 내역**·총 헌금액 조회.
- **사용 단계**: 조직 선택 → 항목·금액 입력 → 결제 → 내역 확인.
- **주의**: 로그인 필요. 조직을 먼저 선택해야 진행 가능.

#### 도매몰 (wholesale.html)

- **목적**: 사업자 회원 전용 도매 주문.
- **주요 기능**: 도매 전용가, 사업자 회원 전용 노출, 간편 주문, **도매몰 입점 신청**(`/api/me/wholesale-applications`), 도매 상품 목록(`/api/wholesale/products`), 도매 주문 목록.
- **사용 단계**: 입점 신청 → 관리자 승인 → 도매가로 주문.
- **주의**: 승인된 사업자 회원만 도매가 열람·주문 가능.

#### 게시판 (board.html, `/board/:type`) · 게시글 상세 (board-detail.html, `/board/:type/:id`)

- **목적**: 공지·커뮤니티 글 열람 및 작성.
- **주요 기능**: 글 목록, **글쓰기**(`POST /api/boards`), 글 상세·댓글 작성/삭제, 본인 글 수정/삭제. (`/notice` 경로는 공지 게시판)
- **사용 단계**: 게시판 선택 → 글 읽기 → (로그인 시) 글쓰기/댓글.
- **주의**: 작성·댓글은 로그인 필요. 관리자는 게시판 관리에서 게시글 상태 변경 가능.

#### 판매자/공급자 등록 (seller.html, partner.html, affiliate.html)

- **seller.html** — 판매자(공급사) 입점 신청(`/api/me/supplier-applications`).
- **partner.html** — 제휴 문의.
- **affiliate.html** — 제휴마케팅 안내.

#### 기타 사용자 화면

- **welcome.html** (`/welcome`): 가입 직후 시작 안내.
- **payment-result.html**: 결제 결과 표시.
- **offline.html** / **404.html**: 오프라인/페이지 없음 안내.

#### 대표자 2단계 인증 (중요)

- **목적**: 계정 탈취 시에도 원가·마진·정산 등 민감 정보를 보호.
- **동작**: 인증 앱(Google Authenticator, Authy 등)의 6자리 코드를 추가 요구. 설정 → 내 계정 2단계 인증에서 TOTP 등록, 또는 대표자 보안설정에서 SMS/이메일 연락처 등록.
- **주의**: 인증수단이 없으면 원가/정산 열람 불가. SMS는 알리고(aligo) 연동이며 키 미설정 시 SMS 수단만 비활성(501), TOTP/이메일은 정상 동작.

> 전제: 해당 회원이 WITH+에 일반 회원으로 먼저 가입되어 있어야 하며, 다른 조직 데이터는 볼 수 없습니다. 정산은 사업자등록 등록·검증 완료 시에만 생성됩니다.

## 5. 주요 업무 흐름

### 5.1 가입 → 탐색 → 장바구니 → 주문 (사용자)

```
회원가입(join) → [휴대폰 인증] → 로그인(login)
   → 메인/카테고리/검색으로 상품 탐색
   → 상품 상세에서 옵션·수량 선택 → 장바구니 담기
   → 장바구니에서 쿠폰·마일리지 적용, 배송지 선택
   → 결제(신용카드/카카오페이/네이버페이)
   → 결제 결과 확인 → 마이페이지에서 주문·배송 추적
```
- 구매 시 개인 마일리지 + (가입/선택) 커뮤니티 적립 동시 발생.

### 5.2 커뮤니티 참여 & 헌금·후원

```
커뮤니티 목록(communities)에서 조직 탐색 → 가입
   → 이후 구매 금액 일부가 해당 공동체에 적립
   → 커뮤니티 랜딩(/c/:slug)에서 내 기여·공동체 총 적립 확인
헌금·후원: /give/:slug → 항목·금액 → 결제 → 내역 확인
```

### 5.3 커뮤니티 글쓰기

```
게시판(/board/:type) → 글쓰기(로그인) → 등록
   → 게시글 상세에서 댓글 작성 → (본인) 수정/삭제
관리자: 게시판 관리에서 게시글 상태 관리
```

### 5.4 제휴·입점

```
판매자 입점: seller → supplier-application 제출 → 관리자 승인 → 공급자 활동
도매 입점: wholesale 입점 신청 → 관리자 승인 → 도매가 주문
제휴: partner/affiliate 문의
```

### 5.5 관리자 운영 흐름

```
상품: 가져오기(엑셀/CSV·공급사 API) 또는 수기 등록 → 카테고리·가격·재고 설정
주문: 주문 관리에서 상태 변경, 반품/교환 처리
마케팅: 세그먼트 발송 / 자동화 규칙 / 쿠폰·프로모션 / 적립율
정산: 기간별 공급사·분양조직 정산 생성 → 세무처리(원천징수/세금계산서)
      → 지급 CSV 또는 자동이체(활성화 시) → 상태 "지급완료"
보안: 대표자 지정 → 2FA 등록 → 원가/정산 열람, 감사로그 점검
```

## 7. FAQ · 문제해결 · 용어집

### 7.1 자주 묻는 질문(FAQ)

**Q. 마일리지와 커뮤니티 적립은 뭐가 다른가요?**
A. 마일리지는 "나"에게 쌓이는 개인 포인트이고, 커뮤니티 적립은 내가 가입/선택한 공동체(분양 조직)에 쌓이는 금액입니다. 구매 시 둘 다 적립됩니다.

**Q. 소셜 로그인은 무엇을 지원하나요?**
A. 네이버 로그인이 백엔드에 연동되어 있습니다(설정은 관리자 OAuth 설정에서 관리).

**Q. 결제 수단은 무엇인가요?**
A. 신용카드(토스), 카카오페이, 네이버페이를 지원합니다.

**Q. 도매가로 사려면?**
A. 도매몰에서 사업자 입점 신청 후 관리자 승인을 받아야 도매 전용가를 볼 수 있습니다.

**Q. 헌금·후원 영수증/내역은 어디서 보나요?**
A. 헌금·후원 화면(`/give/:slug`)의 "내 헌금 내역"에서 확인합니다.

### 7.2 문제해결

| 증상 | 원인/조치 |
|---|---|
| "로그인이 필요한 페이지입니다" | 로그인 후 재시도. |
| "관리자 페이지 접근 권한이 없습니다" | admin/provider 권한 계정으로 로그인 필요. |
| 장바구니 주문 불가 | 비로그인 또는 빈 장바구니 — 로그인·상품 담기 후 진행. |
| 결제가 확정되지 않음 | PG사 승인 콜백(토스 confirm / 카카오·네이버 approve)이 완료돼야 확정됩니다. 결제 결과 화면 확인. |
| 대표자 지정 불가("OWNER_SETUP_CODE 미설정") | Render 환경변수에 `OWNER_SETUP_CODE` 설정 필요. 최초 1회만 claim 가능. |
| 원가/정산 열람 불가 | 대표자 2단계 인증(TOTP/SMS/이메일) 수단을 먼저 등록. |
| SMS 인증 501 오류 | 알리고(aligo) 키 미설정 — TOTP/이메일 수단 사용. |
| 정산 "지급완료 처리" 불가 | 조직 정산 계좌 미등록/미검증 — 분양 조직 관리에서 계좌 등록·검증. |
| AI 카테고리 추천 안 됨 | 설정 → AI 카테고리 추천 카드에서 Anthropic API 키 등록·활성화. |
| 오프라인 화면 표시 | 네트워크 연결 확인(PWA 오프라인 모드). |

### 7.3 용어집

- **PWA**: 홈 화면 추가·오프라인을 지원하는 웹앱 기술(manifest.json, sw.js).
- **분양 조직/커뮤니티**: WITH+가 운영하는 공동체 단위(교회·성당·사찰·단체 등). 전용 랜딩·적립·정산 지원.
- **공동체 적립금**: 구매 금액 일부가 커뮤니티에 쌓이는 금액.
- **마일리지**: 개인 적립 포인트.
- **시리얼 쿠폰**: 1코드당 1명·1회만 사용 가능한 고유 코드. 이벤트 배포용.
- **정산(Settlement)**: 공급사·조직에 매출 대비 금액을 현금 지급하는 절차.
- **원천징수 3.3%**: 사업소득 지급 시 공제하는 세금. 영수증 발급 지원.
- **대표자(Owner)**: 원가·마진·정산 열람 권한 최상위 계정(2FA 필수).
- **TOTP**: 인증 앱 기반 6자리 일회용 코드(2단계 인증).
- **WMS**: 창고관리시스템(재고·로케이션·물류). AGV/디지털트윈은 시뮬레이션.
- **감사로그(Audit Log)**: 관리자의 변경(등록/수정/삭제) 요청 자동 기록.
- **PG**: 결제대행(토스/카카오페이/네이버페이).
